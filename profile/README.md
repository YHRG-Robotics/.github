# YHRG Robotics

欢迎来到 **YHRG Robotics** 🚀
我们专注于 S1 系列机械臂在机器人学习（Robot Learning）方向的开发与落地，包括 ROS2 控制、强化学习、模仿学习以及前沿 VLA / Pi 系列模型的适配。  

---

## 📦 项目列表

### 🔧 [s1_ros2](https://github.com/YHRG-Robotics/s1_ros2)

**说明：**
S1 系列机械臂的 ROS2 官方实现，提供基础控制能力与通信接口。

---

### 🤖 [Evo-RL-theseus](https://github.com/YHRG-Robotics/Evo-RL-theseus)

**说明：**
S1 系列机械臂适配 Evo-RL 仓库，支持 LeRobot 框架，可用于：

* 数据采集
* 模型训练
* 策略推理

---

### 🧠 [openpi-theseus](https://github.com/YHRG-Robotics/openpi-theseus)

**说明：**
S1 系列机械臂适配 OpenPI 算法，支持以下模型：

* pi0
* pi0-fast
* pi0.5

用于高性能策略学习与推理。

---

### 🛠️ [S1_SDK_V2](https://github.com/YHRG-Robotics/S1_SDK_V2)

**说明：**
S1 系列机械臂官方 SDK，提供底层接口与开发支持。
